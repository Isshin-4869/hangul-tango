# ハングル単語帳

韓国語913語の暗記アプリ（間隔反復の復習・カード・学習・テスト・マッチ）。

- 公開ページ: `index.html`（単語データ込みの1ファイル）
- ホーム画面用: `icon-180.png` `icon-512.png` `manifest.webmanifest`
- 編集用: `src/`（`src.html` 本体、`words.json` 単語データ、`build.py` で index.html を再生成、`words.csv` 一覧）

進み具合はブラウザ（localStorage）に保存されます。端末を移るときは「設定 › バックアップをコピー」→移った先で「復元」。
